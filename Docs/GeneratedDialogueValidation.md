# 普通对话不使用预设回复

日期：2026-09-20。Unity 6000.4.6f1。

## 当前行为

- 普通聊天文本由配置的模型生成，流式输出和完整回复均保留模型内容。情绪策略只调整展示表情，不把包含某些关键词的回复替换成固定句子；自然表达由提示词引导。
- 移除回复对象、短期记忆、Android C# / Java TTS 的默认聊天句子。空回复或无效响应报错，未验证的回复不写入记忆；空语音文本不会被替换后播报。
- 空用户输入直接拒绝，不用预设问候代替用户输入。
- 清除记忆等操作仍有固定确认信息，配置、权限和网络错误仍有明确提示。
- 编辑器默认使用真实模型。缺少 API 配置时界面显示配置入口提示；模型失败不会切换到离线测试。
- 离线测试仅通过调试台手动选择，测试回复初始为空，需自行提供。自动化回归测试显式选择测试模式并填写测试数据，不访问真实模型。
