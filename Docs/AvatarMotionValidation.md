# 人物动作复核

复核时间：2026-09-19 至 2026-09-20。Unity 6000.4.6f1，项目模型 `Assets/Models/8590256991748008892.prefab`。

## 发现与修正

- **状态与动作脱节**：从说话切回倾听 0.9 秒后，旧挥手仍在播放，上臂与待机姿势相差 27.58°。现在切出说话状态会释放手臂手势，通过已有姿势平滑器收回；短促点头允许完成。
- **肘部与手腕分别瞄准**：原逻辑独立指向肘部、手腕目标，手腕实际位置偏离预期。思考动作接近完全折叠，解释动作几乎直臂。现在按实际骨长联合求解两个关节，用肘部提示点确定弯曲平面，并将前臂约束在当前 VRM 骨架的肘部弯曲轴上。
- **待机与思考的手形**：待机时改为轻微屈肘，手不再偏向身后；显式思考手势与思考状态使用一致的姿势和手指弯曲。

- 61 项 EditMode 测试通过。

- 以每秒 60 帧采样待机、倾听、思考状态及点头、挥手、思考、解释手势，每种动作采样 3 秒。
- 上下臂骨长变化小于 0.1 毫米；检查的肩、肘、腕、胸、头及手指处于 Humanoid 配置范围内（归一化值允许 0.05 的测量容差）。
- 对每种姿势保存正面、斜侧面和侧面图；目视复核关键姿势，未见明显手臂穿身。另生成 14 秒连续对话预览用于检查衔接。

## 交谈表情与小幅动作

- 浅笑使用嘴角、眉和眼的局部形变。关切主要使用眉眼，播报口型仍独立驱动。整体表情会随口型和眨眼衰减，惊讶在同一句中会自行收敛，切到聆听后逐渐回到中性。
- 温和追问可触发轻偏头，轻声建议可触发单手低位示意。伸手沿用原有肘部约束和缓动，手腕保持在胸口下方、身体侧前方。挥手减小摆幅，解释动作采用一次轻拍式抬手。
- Unity 回归使用实际模型检查局部形变、口型、关节范围、骨长和新动作的位置，并可输出正面、斜侧面和侧面图。
- 2026-11-16 的模型采样中，轻偏头较待机侧倾约 5.7°，低位示意的右肘最大屈曲约 49.3°。三视角关键帧和关节日志位于 `Builds/Validation/natural-avatar-motion-20261116-223502/`。
