# Embedded face-expression model

`hsemotion_enet_b0_8_best_afew.bytes` is generated by
`Tools/Export-HseEmotionOnnx.py` from the pinned HSEmotion AFEW checkpoint.

- Source: https://github.com/av-savchenko/hsemotion
- Architecture: EfficientNet-B0, 224 x 224 RGB input, eight apparent-expression logits
- Exported ONNX SHA-256: `91d08b5d1cb7dd5edd716d24a502bfe16af65352de65d1092bc370dd438c10f2`
- Project mapping: anger, happiness, sadness and surprise map to the matching SRTP labels;
  unsupported contempt, disgust and fear are conservatively folded into neutral.
- HSEmotion code license: Apache-2.0

The model runs locally on the Android device. Camera frames are not persisted by
the native bridge and are not uploaded in standalone mode.
